Type: AB Test

Objective:

Hypothesis:
IF we add an "Add to Cart" CTA to each of the three membership tier cards, which scrolls the visitor down to the buy box,

THEN membership sales will increase,

BECAUSE heatmap data shows visitors currently stop scrolling once they've read the three tier cards and never reach the purchase mechanism further down the page.

url: https://onedaytests.com/products/membership

audience: all

kpi: clicks on newly added CTAs (can be tracked all together with the same .class), Add to cart on membership page, app revenue



Test details:

Add a clear CTA button to each of the three tier cards (Flex, Performance, Longevity) — currently none of the three cards has any clickable CTA at all.

On click, the CTA should: (1) scroll the page down to the existing "STEP 1 - CHOOSE YOUR MEMBERSHIP TIER" buy-box panel, and (2) automatically pre-select the radio button matching the tier that was clicked, so the visitor doesn't have to re-identify and re-select the same plan a second time.

Copy change in the membership card (only the first point): the % of the test discount is moved from below the check mark to the title "15% off any other test" etc.

Add a clear cancellation/no-lock-in statement directly on or near the three tier cards themselves (e.g. "Cancel anytime, no minimum term")
